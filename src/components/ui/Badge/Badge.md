# Badge

เอกสารการใช้งานสำหรับนักออกแบบและ AI agent ที่สร้าง UI · ตัวอย่างที่กดลองได้อยู่ใน Storybook `Components/Badge`

---

## Import and usage (วิธี import และใช้งาน)

1. Import จากโฟลเดอร์ของ component และไอคอนจาก `lucide-react`

   ```tsx
   import { Badge } from "@/components/ui/Badge"
   import { CircleCheckIcon } from "lucide-react"
   ```

2. เลือกระดับสถานะจากตารางใน "When to use" แล้วใส่**ไอคอน + ข้อความ**เสมอ ไอคอนใส่ `aria-hidden`

   ```tsx
   <Badge variant="success">
     <CircleCheckIcon data-icon="inline-start" aria-hidden />
     ชำระแล้ว
   </Badge>
   ```

3. ป้ายหมวดหมู่ (ไม่ใช่สถานะ) ใช้ `secondary` ไม่ต้องมีไอคอน

   ```tsx
   <Badge variant="secondary">ทาวน์เฮาส์</Badge>
   ```

---

## 1. Purpose

ป้ายเล็กที่บอกสถานะหรือหมวดหมู่ของข้อมูล ให้อ่านแล้วรู้ทันทีโดยไม่ต้องกด

## 2. When to use (ควรใช้ตอนไหน)

### สถานะ: เลือกระดับก่อน แล้วใช้ variant ของระดับนั้น

| ระดับ     | variant       | สถานะในแอป                     | ไอคอน                   |
| --------- | ------------- | ------------------------------ | ----------------------- |
| เรียบร้อย | `success`     | ชำระแล้ว, มีผู้เช่า, เสร็จแล้ว | วงกลมมีเครื่องหมายถูก   |
| ข้อมูล    | `outline`     | ว่าง, ยังไม่เริ่ม              | วงกลมเส้นประ            |
| จับตา     | `warning`     | ใกล้ครบกำหนด, สัญญาใกล้หมด     | นาฬิกา / ปฏิทินมีนาฬิกา |
| รีบจัดการ | `destructive` | ค้างชำระ                       | วงกลมมีเครื่องหมายตกใจ  |

- Badge สถานะต้องมี**ข้อความ**เสมอ และมี**ไอคอน**ด้วย เว้นแต่แถวนั้นมีไอคอนสถานะเดียวกันอยู่แล้ว ห้ามบอกสถานะด้วยสีอย่างเดียว
- สถานะใหม่ (เช่นงานซ่อมในเฟส 5) ให้จัดเข้าหนึ่งใน 4 ระดับนี้ ไม่สร้างสีใหม่

### ป้ายอื่น

- **หมวดหมู่** (ทาวน์เฮาส์, ประปา, แอร์): `secondary` ไม่ต้องมีไอคอน
- **ป้ายเน้น** เช่น "ใหม่": `default` (สีแบรนด์)
- **ป้ายที่กดไปดูรายละเอียดได้** เช่น "ดูสัญญา": ทำ Badge ให้เป็นลิงก์ (ดูส่วนที่ 4)

## 3. When not to use (ไม่ควรใช้ตอนไหน)

- **ต้องกดเพื่อสั่งงาน** (ส่ง, ลบ, บันทึก): ใช้ `Button`
- **ข้อความยาวหรือหลายบรรทัด**: Badge ไม่ตัดบรรทัด ใช้ข้อความธรรมดาหรือ `Card`
- **แจ้งผลหลังทำอะไรเสร็จ** (บันทึกแล้ว, ส่งแล้ว): ใช้ toast ซึ่งหายไปเอง
- **ตัวเลขหรือจำนวนเงินสำคัญ** (ยอดค้าง, KPI): แสดงเป็นตัวเลขขนาดปกติ อย่าย่อลงใน Badge
- **`default` กับสถานะ**: สีแบรนด์เป็นส้ม ใกล้กับเหลืองของ `warning` จะสับสนกับ "จับตา"
- **`secondary` กับสถานะ**: เทาเป็นของหมวดหมู่ ใช้กับสถานะแล้วจะไม่รู้ว่าอยู่ระดับไหน
- **ทำไมสถานะเรียบร้อยเป็นเขียว**: ทีมเลือกเพราะดูดีและให้ความรู้สึกบวก ข้อแลกคือตารางที่ส่วนใหญ่ชำระแล้วจะเขียวเยอะ ถ้าใช้จริงแล้วรก ทางสำรองคือป้ายเทาที่ไอคอนเป็นเขียว
- TODO: Badge มีสไตล์ "ข้อมูลไม่ถูกต้อง" (ขอบแดง) ติดมาจาก shadcn แต่ยังไม่มีกรณีใช้งานในแอป ต้องตัดสินว่า Badge ควรมีสถานะนี้หรือไม่

## 4. Props and variants

**`variant`** ค่าเริ่มต้น `default`

| variant       | หน้าตา                      | contrast ตัวอักษร (สว่าง / มืด) |
| ------------- | --------------------------- | ------------------------------- |
| `default`     | พื้นสีแบรนด์ (ส้ม) ตัวขาว   | 4.85 / 6.84                     |
| `secondary`   | พื้นเทาอ่อน ตัวเข้ม         | 16.12 / 14.27                   |
| `outline`     | ไม่มีพื้น มีเส้นขอบเทา      | 19.76 / 16.74                   |
| `success`     | พื้นเขียวอ่อน ตัวเขียวเข้ม  | 5.08 / 5.76                     |
| `warning`     | พื้นเหลืองอ่อน ตัวอำพันเข้ม | 5.33 / 6.10                     |
| `destructive` | พื้นแดงอ่อน ตัวแดงเข้ม      | 4.83 / 4.90                     |

ค่า contrast วัดบนพื้น Card ทุกค่าผ่านเกณฑ์ WCAG AA (4.5:1)

**ทำเป็นลิงก์** Badge เปลี่ยนเป็นลิงก์ได้ ตอนชี้เมาส์สีพื้นจะเปลี่ยนเล็กน้อย และกด Tab มาถึงจะมีวง focus

**ขนาด** ไม่มีให้เลือก ทุก Badge สูง 20px ตัวอักษรเล็ก มุมโค้งเต็ม ไอคอนขนาด 12px

**สิ่งที่ต้องใส่เองตอนใช้** ไอคอนคู่ข้อความ ใส่ `data-icon="inline-start"` (ไอคอนอยู่หน้า) หรือ `"inline-end"` (อยู่หลัง) บนไอคอน ป้ายจะปรับระยะขอบฝั่งนั้นให้สมดุล และไอคอนสถานะใส่ `aria-hidden` เพราะข้อความบอกความหมายครบแล้ว

## 6. Example

จาก story `Status` (ตัดมา 4 จาก 6 สถานะ):

```tsx
<Badge variant="success">
  <CircleCheckIcon data-icon="inline-start" aria-hidden />
  ชำระแล้ว
</Badge>
<Badge variant="outline">
  <CircleDashedIcon data-icon="inline-start" aria-hidden />
  ว่าง
</Badge>
<Badge variant="warning">
  <ClockIcon data-icon="inline-start" aria-hidden />
  ใกล้ครบกำหนด
</Badge>
<Badge variant="destructive">
  <CircleAlertIcon data-icon="inline-start" aria-hidden />
  ค้างชำระ
</Badge>
```

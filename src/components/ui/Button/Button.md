# Button

เอกสารการใช้งานสำหรับนักออกแบบและ AI agent ที่สร้าง UI · ตัวอย่างที่กดลองได้อยู่ใน Storybook `Components/Button`

---

## 1. Purpose

ปุ่มที่ผู้ใช้กดเพื่อสั่งให้เกิด action ในหน้านั้น เช่น บันทึก ส่ง ลบ เปิดหน้าต่าง

## 2. When to use (ควรใช้ตอนไหน)

| สถานการณ์                                                     | ใช้แบบนี้                                              |
| ------------------------------------------------------------- | ------------------------------------------------------ |
| action หลักของฟอร์มหรือหน้า (มีได้ **1 ปุ่ม**ต่อพื้นที่)      | `default` เช่น "บันทึก", "เข้าสู่ระบบ"                 |
| ปุ่มหลักในฟอร์มแคบ (หน้าเข้าสู่ระบบ, สมัครสมาชิก)             | `default` ขนาด `lg` กว้างเต็มฟอร์ม                     |
| action รองที่วางคู่กับปุ่มหลัก (ยกเลิก, ย้อนกลับ, ส่งออก)     | `outline`                                              |
| ปุ่มที่เปิดการลบ (ยังไม่ลบจริง)                               | `destructive` (แดงอ่อน) แล้วเปิด AlertDialog ให้ยืนยัน |
| ปุ่มยืนยันลบครั้งสุดท้ายใน AlertDialog (ย้อนกลับไม่ได้)       | `destructive-solid` (แดงทึบ)                           |
| ปุ่มเล็กใน toolbar, เมนู, หัวตาราง หรือปุ่มไอคอนในช่องกรอก    | `ghost` ขนาด `icon-*` พร้อม `aria-label` ภาษาไทย       |
| action สั้นๆ ที่แทรกในประโยค และไม่เปลี่ยนหน้า                | `link` เช่น "กรอกให้อัตโนมัติ" ในหน้าเข้าสู่ระบบ       |
| เปิด Dialog, Sheet, เมนู หรือ Tooltip                         | ปุ่มเป็นตัวเปิดของ overlay นั้น ส่วนใหญ่ใช้ `outline`  |
| กำลังส่งข้อมูล รอผล                                           | ใส่ `loading` ปุ่มจะหมุนและกดซ้ำไม่ได้เอง              |
| ปุ่มที่เกี่ยวข้องกันหลายปุ่มติดเป็นแถบ (ช่วงเวลา, เลื่อนหน้า) | ห่อด้วย `ButtonGroup`                                  |

## 3. When not to use (ไม่ควรใช้ตอนไหน)

- **พาไปหน้าอื่น** (เปลี่ยน URL): ใช้ลิงก์ ถ้าอยากให้ลิงก์หน้าตาเป็นปุ่ม ให้ทำปุ่มเป็นลิงก์ (ดูส่วนที่ 4) เพราะโปรแกรมอ่านหน้าจอจะได้บอกว่าเป็นลิงก์ ไม่ใช่ปุ่ม
- **เปิด/ปิดค่า**: ใช้ `Switch` หรือ `Checkbox` ปุ่มคือการสั่งงาน ไม่ใช่การเก็บค่า
- **เลือก 1 จากหลายตัวเลือก**: ใช้ `Select` หรือ `Tabs`
- **แสดงสถานะ** (ชำระแล้ว, ค้างชำระ): ใช้ `Badge` ซึ่งเป็นป้าย ไม่ใช่สิ่งที่กดได้
- **ปุ่ม `default` มากกว่า 1 ปุ่มในพื้นที่เดียวกัน**: ปุ่มที่เหลือลดเป็น `outline` หรือ `ghost`
- **`destructive-solid` นอก AlertDialog**: ถ้าแดงทึบทุกที่ ปุ่มยืนยันลบจะไม่เด่นอีกต่อไป
- **`link` ที่อยู่เดี่ยวๆ นอกประโยค**: ต้องมีพื้นที่กดหรือระยะรอบๆ อย่างน้อย 24px (WCAG 2.5.8)
- **ไม่มี `secondary` (ตั้งใจ)**: ปุ่มรองใช้ `outline` อย่างเดียว เพราะทุกปุ่มในแอปวางบนพื้นขาว และกฎเดียวทำให้ไม่ต้องลังเล ระบบใหญ่อย่าง Primer, Atlassian, Ant Design ก็มีปุ่มระดับกลางแบบเดียว ถ้าวันหน้าต้องวางปุ่มบนพื้นสีแล้ว `outline` ดูจม ให้กลับมาตัดสินใหม่
- **สีลิงก์แยกจากสีแบรนด์ (ตั้งใจ)**: สีแบรนด์ในโหมดมืดเข้มเกินไปสำหรับตัวอักษร (contrast 2.45:1 ไม่ผ่าน) จึงเพิ่ม token `--link` ที่สว่างขึ้นในโหมดมืด ลิงก์ข้อความทุกที่ (รวมลิงก์ "สมัครสมาชิก") ใช้สีนี้ ส่วนพื้นปุ่ม `default` ยังใช้สีแบรนด์เหมือนเดิม

## 4. Props and variants

**`variant`** ค่าเริ่มต้น `default`

| variant             | หน้าตา                                                                  | contrast ตัวอักษร (สว่าง / มืด) |
| ------------------- | ----------------------------------------------------------------------- | ------------------------------- |
| `default`           | พื้นสีแบรนด์ (ส้ม) ตัวขาว                                               | 4.85 / 6.84                     |
| `outline`           | พื้นขาว เส้นขอบเทา                                                      | –                               |
| `ghost`             | ไม่มีพื้นและขอบ มีพื้นเทาตอนชี้เมาส์                                    | –                               |
| `destructive`       | พื้นแดงอ่อน ตัวแดงเข้ม                                                  | 4.83 / 4.90                     |
| `destructive-solid` | พื้นแดงทึบ ตัวขาว (โหมดมืด: ตัวเข้ม)                                    | 5.58 / 7.05                     |
| `link`              | ตัวสีลิงก์ (ส้ม) ไม่มีพื้น ขีดเส้นใต้ตอนชี้เมาส์ ไม่มีความสูงและระยะขอบ | 4.61 / 5.38                     |

`outline` และ `ghost` ใช้ตัวอักษรสีหลักบนพื้นขาวหรือเทาอ่อน อ่านง่ายมาก จึงไม่ได้วัดแยก

**`size`** ค่าเริ่มต้น `default`

| size      | ขนาด                | ใช้กับ                   |
| --------- | ------------------- | ------------------------ |
| `xs`      | สูง 24px ตัวเล็กสุด | ปุ่มในพื้นที่แน่นมาก     |
| `sm`      | สูง 28px            | ปุ่มในตาราง หรือ toolbar |
| `default` | สูง 32px            | ปุ่มทั่วไป               |
| `lg`      | สูง 36px            | ปุ่มหลักในฟอร์มแคบ       |
| `icon-xs` | 24×24               | ปุ่มไอคอนเล็กสุด         |
| `icon-sm` | 28×28               | ปุ่มไอคอนในตาราง         |
| `icon`    | 32×32               | ปุ่มไอคอนทั่วไป          |
| `icon-lg` | 36×36               | ปุ่มไอคอนใหญ่            |

`link` ไม่สนใจความสูงของ size ใช้แค่ขนาดตัวอักษร

**`loading`** ค่าเริ่มต้น ไม่หมุน ใส่แล้วปุ่มจะมีไอคอนหมุนนำหน้า กดซ้ำไม่ได้ และบอกโปรแกรมอ่านหน้าจอว่ากำลังทำงาน ปุ่มไอคอนจะหมุนแทนไอคอนเดิม

**`disabled`** ปุ่มจางลงครึ่งหนึ่งและกดไม่ได้

**สิ่งที่ต้องใส่เองตอนใช้**

- **ไอคอนคู่ข้อความ:** ใส่ `data-icon="inline-start"` (ไอคอนอยู่หน้า) หรือ `"inline-end"` (อยู่หลัง) บนไอคอน ปุ่มจะปรับระยะขอบฝั่งนั้นให้สมดุล
- **ปุ่มที่มีแต่ไอคอน:** ต้องมี `aria-label` ภาษาไทยเสมอ เช่น `aria-label="แก้ไข"`
- **ทำปุ่มเป็นลิงก์:** `render={<Link href="…" />}` คู่กับ `nativeButton={false}`

**สถานะอื่นที่เกิดเอง:** กด Tab มาถึงจะมีวง focus (ปุ่มแดงใช้วงสีแดง), ตอนกดปุ่มเลื่อนลง 1px, ตอนเป็นตัวเปิดเมนูที่เปิดอยู่ `outline` กับ `ghost` จะค้างสีพื้นไว้

| `--primary`                | `oklch(0.555 0.163 48.998)` | `oklch(0.473 0.137 46.201)`  | พื้น `default`                      |
| `--primary-foreground`     | `oklch(0.987 0.022 95.277)` | `oklch(0.987 0.022 95.277)`  | ตัวอักษร `default`                  |
| `--link`                   | `oklch(0.555 0.163 48.998)` | `oklch(0.7 0.15 55)`         | ตัวอักษร `link`                     |
| `--background`             | `oklch(1 0 0)`              | `oklch(0.147 0.004 49.25)`   | พื้น `outline`                      |
| `--border`                 | `oklch(0.923 0.003 48.717)` | `oklch(1 0 0 / 10%)`         | เส้นขอบ `outline` (สว่าง)           |
| `--input`                  | `oklch(0.923 0.003 48.717)` | `oklch(1 0 0 / 15%)`         | เส้นขอบและพื้น `outline` (มืด)      |

| `--destructive-foreground` | `oklch(0.985 0 0)`          | `oklch(0.205 0 0)`           | ตัวอักษร `destructive-solid`        |

| `--radius`                 | `0.625rem` (10px)           | –                            | มุมโค้งของปุ่ม (ขนาดเล็กโค้งน้อยลง) |

## 6. Example

จาก story `WithIcon`:

```tsx
<Button>
  <PlusIcon data-icon="inline-start" />
  เพิ่มบ้านเช่า
</Button>
<Button variant="destructive">
  <Trash2Icon data-icon="inline-start" />
  ลบผู้เช่า
</Button>
```
